    API Reference¶

    Capabilities and limits¶

    STEP preparation and JAX evaluation¶

    STEP reading and OCCT extraction run on the host, outside jit, vmap, and differentiation. The numerical kernels operate on the resulting arrays and geometric models; JAX transformation support follows each API's contract.

    Face conversion and mesh extraction support planes, cylinders, spheres, cones, tori, and B-spline surfaces (including rational weights). Other OCCT surface types are unsupported. face_to_primitive warns and returns None for them; mesh extraction raises NotImplementedError rather than returning an incomplete mesh. CSG reconstruction also rejects unsupported faces. Successful conversion alone does not establish an accurate solid SDF.

    extract_mesh_topology and evaluate_mesh separate OCCT preparation from JAX vertex evaluation. Connectivity and the extracted UV samples form a fixed discretization; uv_scale_param can scale plane UV coordinates so that caps follow a linked parameter. Parameter changes must preserve closure and shared boundaries; a derivative of this discretization is not a derivative through OCCT reconstruction or remeshing. Topology-changing edits require separate validation.

    Mesh mass properties¶

    For a watertight, consistently oriented mesh, the divergence theorem gives the mesh's signed volume. Accuracy against the original curved CAD depends on tessellation. The integration report records fixture measurements, not an error bound for every supported surface or input.

    Function Numerical contract
    divergence_volume Cubic polynomial in triangle vertices; signed volume in length cubed.
    mesh_surface_area Sum of triangle areas, in length squared; uses a norm, not a polynomial. Collapsed triangles use a chosen zero subgradient.
    mesh_center_of_mass First moments divided by volume, in length units; undefined for nonempty zero-volume inputs.
    mesh_inertia_tensor Tensor about the center of mass at unit density, in length to the fifth power; requires nonzero volume and outward orientation.

    Nearly degenerate solids can make the normalized moments ill-conditioned. See the function contracts below for empty-input behavior and other assumptions.

    Boolean measures and trimmed surfaces¶

    Union, intersection, and subtraction have stratum-dispatched measure implementations. Where finite primitive volume formulas apply, disjoint and contained configurations use analytical gradients. Intersecting configurations and other fallbacks differentiate a smoothed indicator on a frozen grid as a surrogate for the hard sampled forward measure. These estimators have discretization error and do not establish exact derivatives through arbitrary CAD topology changes. See Boolean operations for the APIs.

    Standalone trimmed-face distances and CSG half-space composition have different contracts. TrimmedCSGStump uses raw primitive SDFs in its DNF composition, including B-splines; trim frames are retained as metadata. ADR-0020 explains why the trim-aware blend is excluded from that composition. See NURBS differentiation scope for the remaining distinction between surface, face, and solid derivatives.

    def read_step(path: str | Path) -> TopoDS_Shape:
    """Read a STEP file and return the top-level shape.

    Args:
        path: Path to the STEP file (.step or .stp).

    Returns:
        The parsed OCCT shape.

    Raises:
        FileNotFoundError: If the file does not exist.
        ValueError: If the STEP file cannot be parsed.
    """
    resolved = Path(path).resolve()
    if not resolved.is_file():
        msg = f"STEP file not found: {resolved}"
        raise FileNotFoundError(msg)

    reader = STEPControl_Reader()
    status = reader.ReadFile(str(resolved))
    if status != IFSelect_RetDone:
        msg = f"Failed to read STEP file (status={status}): {resolved}"
        raise ValueError(msg)

    reader.TransferRoots()
    shape = reader.OneShape()
    if shape.IsNull():
        msg = f"STEP file produced a null shape: {resolved}"
        raise ValueError(msg)

    return shape

    def face_to_primitive(face: TopoDS_Face) -> Primitive | None:
    """Convert a single OCP face to a BRepAX Primitive.

    Maps planes, cylinders, spheres, cones, tori, and B-spline surfaces
    (including rational weights) to BRepAX primitives, extracting geometric
    parameters via OCCT adaptor classes. This is host-side preparation.

    Returns None with a warning for other surface types.

    Args:
        face: An OCCT topological face.

    Returns:
        A :class:`Primitive` instance, or ``None`` if the surface type
        is not supported.
    """
    adaptor = BRepAdaptor_Surface(face)
    stype = adaptor.GetType()

    if stype == GeomAbs_Plane:
        gp_plane = adaptor.Plane()
        point = _gp_pnt_to_array(gp_plane.Location())
        normal = _gp_dir_to_array(gp_plane.Axis().Direction())
        offset = jnp.dot(normal, point)
        return PlanePrim(normal=normal, offset=offset)

    if stype == GeomAbs_Cylinder:
        gp_cyl = adaptor.Cylinder()
        point = _gp_pnt_to_array(gp_cyl.Location())
        axis = _gp_dir_to_array(gp_cyl.Axis().Direction())
        radius = jnp.array(gp_cyl.Radius())
        return CylinderPrim(point=point, axis=axis, radius=radius)

    if stype == GeomAbs_Sphere:
        gp_sph = adaptor.Sphere()
        center = _gp_pnt_to_array(gp_sph.Location())
        radius = jnp.array(gp_sph.Radius())
        return SpherePrim(center=center, radius=radius)

    if stype == GeomAbs_Cone:
        gp_cone = adaptor.Cone()
        apex = _gp_pnt_to_array(gp_cone.Apex())
        axis = _gp_dir_to_array(gp_cone.Axis().Direction())
        angle = jnp.array(abs(gp_cone.SemiAngle()))
        return ConePrim(apex=apex, axis=axis, angle=angle)

    if stype == GeomAbs_Torus:
        gp_torus = adaptor.Torus()
        center = _gp_pnt_to_array(gp_torus.Location())
        axis = _gp_dir_to_array(gp_torus.Axis().Direction())
        major_radius = jnp.array(gp_torus.MajorRadius())
        minor_radius = jnp.array(gp_torus.MinorRadius())
        return TorusPrim(
            center=center,
            axis=axis,
            major_radius=major_radius,
            minor_radius=minor_radius,
        )

    if stype == GeomAbs_BSplineSurface:
        return _convert_bspline_face(adaptor, face)

    type_name = _SURFACE_TYPE_NAMES.get(stype, "unknown")
    warnings.warn(
        f"Unsupported surface type: {type_name}, skipping face",
        stacklevel=2,
    )
    return None

    brepax.brep.triangulate ¶

    Triangulation of B-Rep faces for divergence theorem volume.

    Uses OCCT BRepMesh for watertight mesh topology, then re-evaluates vertex positions inside the JAX computation graph using parametric surface functions. This gives jax.grad flow from volume through triangle vertices to primitive parameters (control points, radius, etc.) while preserving mesh watertightness.

    triangulate_shape(shape, *, deflection=_DEFAULT_DEFLECTION) ¶

    Triangulate all faces of a shape with JAX-native vertices.

    Uses OCCT BRepMesh for watertight mesh topology, then re-evaluates each vertex position using JAX-native parametric surface functions. Faces are grouped by surface type (and BSpline signature) so each group is evaluated with a single batched jax.vmap, eliminating per-face Python dispatch overhead.

    evaluate_mesh(topology, overrides=None, *, uv_scale_param=None) ¶

    Re-evaluate mesh vertices from topology with parameter overrides.

    For each face, evaluates the surface function at the stored UV coordinates using surface parameters. Any parameter in overrides replaces the corresponding stored value, allowing jax.grad to flow from volume through vertices to the overridden design parameter.

    When uv_scale_param is set, plane faces scale their UV coordinates by overrides[uv_scale_param] / uv_scale_ref so that flat caps follow curved-surface parameter changes (e.g. disk caps scale with cylinder radius).

    Parameters:

    Name Type Description Default
    topology list[dict[str, Any]]

    Face list from :func:extract_mesh_topology.

    		 required
    overrides dict[str, ndarray] | None

    Parameter name-value pairs to override.

    		 None
    uv_scale_param str | None

    Override key used to scale plane UV coordinates. Required for multi-face optimization where flat caps must track a curved-surface parameter.

    		 None

    Returns:

    Type Description
    ndarray

    Triangle vertices, shape (n_total, 3, 3).

    Examples:

...     )
>>> grad = jax.grad(volume_fn)(jnp.array(5.0))

    divergence_volume(triangles) ¶

    Compute volume of a closed triangle mesh via the divergence theorem.

    Uses the signed-tetrahedra formula in a local frame near the mesh: each triangle and the local origin form a tetrahedron whose signed volume is v0 . (v1 x v2) / 6. The sum over all triangles gives the enclosed volume for a watertight mesh with outward-facing normals.

    Local coordinates reduce cancellation for solids far from the world origin. Units are length cubed. Empty meshes return zero.

    jax.grad differentiates the frozen mesh. Geometric shape derivatives require shared boundaries to move consistently and preserve closure; independently moving duplicated triangle corners can open the mesh.

    Parameters:

    Name Type Description Default
    triangles ndarray

    Triangle vertices, shape (n, 3, 3).

    		 required

    Returns:

    Type Description
    ndarray

    Enclosed volume (scalar).

    Examples:

    >>> shape = read_step("model.step")
>>> tris, params = triangulate_shape(shape)
>>> vol = divergence_volume(tris)
>>> grad = jax.grad(divergence_volume)(tris)

    mesh_surface_area(triangles) ¶

    Compute surface area of a triangle mesh.

    Sums the area of each triangle: (1/2) ||cross(e1, e2)||. Units are length squared. No absolute area floor is applied. Collapsed or collinear triangles have zero area with a chosen zero subgradient at the nondifferentiable point. Empty meshes return zero.

    Name Type Description Default
    triangles ndarray

    Triangle vertices, shape (n, 3, 3).

    		 required

    Returns:

    Type Description
    ndarray

    Total surface area (scalar).

    Examples:

    >>> tris, _ = triangulate_shape(shape)
>>> area = mesh_surface_area(tris)

    mesh_center_of_mass(triangles) ¶

    Compute center of mass of a closed triangle mesh.

    Integrates signed tetrahedron first moments in a local frame, then divides by signed volume. This avoids cancelling world-origin moments and introducing a dimensionful epsilon into the denominator.

    Assumes a watertight mesh with nonzero volume. Units are length. Empty meshes return zero. For nonempty zero-volume inputs the center is undefined; nearly degenerate solids are ill-conditioned. Shape derivatives require closure-preserving shared-boundary motion.

    Parameters:

    Name Type Description Default
    triangles ndarray

    Triangle vertices, shape (n, 3, 3).

    		 required

    Returns:

    Type Description
    ndarray

    Center of mass, shape (3,).

    Examples:

    >>> tris, _ = triangulate_shape(shape)
>>> com = mesh_center_of_mass(tris)

    mesh_inertia_tensor(triangles) ¶

    Compute the inertia tensor of a closed triangle mesh about its center of mass.

    Integrates signed tetrahedron moments (Tonon 2005), then applies the parallel axis theorem in a local frame near the center of mass. See https://doi.org/10.3844/jmssp.2005.8.11 for tetrahedron moments.

    Assumes a watertight, outward-oriented mesh with nonzero volume and uniform density rho = 1. Empty meshes return zero. Length units L give inertia units L**5; uniform scaling by s multiplies the tensor by s**5. Nearly degenerate solids are ill-conditioned.

    Parameters:

    Name Type Description Default
    triangles ndarray

    Triangle vertices, shape (n, 3, 3).

    		 required

    Returns:

    Type Description
    ndarray

    Symmetric 3x3 inertia tensor about center of mass.

    Examples:

    >>> tris, _ = triangulate_shape(shape)
>>> I = mesh_inertia_tensor(tris)
